# Keyboard and Mouse

On a Mac use Cmd instead of Ctrl.

## Keyboard

| Keys | Action |
|---|---|
| **Ctrl+O** | import (open) files |
| **Space** | play / pause |
| **+** / **−** | zoom the timeline in / out (the number-pad keys work too; Ctrl + and − still zoom the browser page) |
| **L** | cycle the map layer (dark, light, satellite) |
| **Ctrl+Z** | undo |
| **Ctrl+Shift+Z**, **Ctrl+Y** | redo |
| **Ctrl+S** | save |
| **Esc** | close the open menu or dialog without applying; otherwise clear the selection |

**Typing is never hijacked.** Shortcuts such as Space and L are ignored while you type in any field, including the
fields inside the GPX converter dialog, and while a dialog is open. Ctrl+O and Ctrl+S still work in a field.
Buttons and links keep Space and Enter for themselves.

### Esc order

1. an open track menu closes first,
2. then an open dialog (trim) closes **without saving** (the GPX import dialog closes the same way),
3. otherwise the selection is cleared.

### Inside the trim dialog

With a range handle focused: **← →** move it by 1 s, **Shift+← →** (or PageUp/PageDown) by 10 s, **Home/End** to the
ends.

## Mouse and touch

| Gesture | Where | Action |
|---|---|---|
| drop one or several files | map, timeline | import all of them (`.jfs`, `.gpx`) |
| click | path, arrow, legend entry, timeline row | select the track |
| click | empty map | clear selection |
| right-click | timeline row | track actions menu |
| drag | timeline row | move the track in time |
| click / drag | ruler | scrub the playhead |
| wheel | timeline chart or ruler | zoom |
| Ctrl + wheel | timeline chart | pan |
| Shift + wheel | timeline | scroll rows vertically |
| wheel, drag | map | zoom, pan |

Touch screens use the same drags. Buttons and dialog controls are at least 44 px high.
